# CINEMA WATCH

한국 영화관 **좌석 / 예매오픈 실시간 감시 콘솔**. 인자 없이 실행하면 배너가 뜨고,
방향키로 영화관 → 지역 → 지점 → 영화 → 요일 → 상영관 → 좌석을 골라 감시 조건을 만듭니다.
표준 라이브러리만 씁니다 (Python 3.10+, 설치 불필요).

```bash
python cinema_watch.py
```

첫 화면에는 프로그램 배너가 뜨고, 영화관을 고르면 그 브랜드의 배너로 바뀝니다.

## 지원 브랜드

첫 화면에서 영화관을 고르면 그 브랜드의 배너로 바뀝니다.
브랜드마다 공개된 데이터의 깊이가 달라 지원 범위도 다릅니다 (2026-08-28 실측).

| 브랜드 | 지점 | 상영표 · 잔여석 | 좌석표 | 비고 |
|---|:---:|:---:|:---:|---|
| **롯데시네마** | O | O | **O** | 좌석 지정 · 명당 추천까지 전부 |
| **메가박스** | O | O | **O** | 좌석선택 화면 API 로 좌석 지정 · 명당 추천까지 |
| **CGV** | O | O | X | 상영표 API 로 잔여석까지. 좌석 화면은 로그인을 요구해 막힘 |

좌석표를 쓸 수 없는 브랜드에서는 좌석 지정·명당 모드가 자동으로 감춰지고
`잔여석이 N석 이상 생기면` 조건으로 감시합니다.

## 세 가지 모드

**좌석 감시** — 정해둔 자리가 비면(취소표) 알림
> 예) 롯데시네마 월드타워 · 오디세이 · 월~금 · 21관 · 2인 · `G22,G23` 또는 `F22,F23`

**예매오픈 감시** — 특정 날짜 예매가 열리면 알림 (예상 오픈 시점도 함께 표시)
> 예) 메가박스 강남 · 오디세이 · 9/8

**예매 오픈 패턴** — 예매가 언제 열리는지 측정·기록·예측

**좌석 확인** — 감시를 걸지 않고 회차 하나를 골라 지금 상태를 바로 봅니다.
지점 → 날짜 → 회차를 고르면 좌석 배치가 그려지고(롯데·메가박스), 명당도 함께 표시됩니다.
`r` 로 새로고침. CGV 는 좌석표가 없어 잔여석까지 보여줍니다.

## 즐겨찾기

메뉴의 **즐겨찾기 관리**에서 자주 가는 지점과 상영관을 브랜드별로 등록해두면,

- 지역 선택 화면 맨 위에 `★ 즐겨찾는 지점` 항목이 생기고
- 지점·상영관 목록에서 즐겨찾기가 **맨 위에 ★ 로 정렬**되며
- 상영관 선택 시 즐겨찾는 상영관이 **미리 선택된 상태**로 뜹니다

## 적응형 폴링 · 변동 이력

무작정 전 회차를 같은 주기로 훑지 않습니다. **상영표 조회 1번이면 그 날짜 모든 회차의
잔여석을 알 수 있고, 잔여석이 늘어난 순간이 곧 누군가 취소한 순간**이라는 점을 이용합니다.

1. 오늘·내일 상영표는 매 주기 새로 받습니다 (날짜당 1회 호출)
2. 잔여석이 **늘어난 회차는 그 자리에서 즉시** 좌석표를 조회합니다 (`[취소표]` 표시)
3. 나머지는 상황에 따라 간격을 달리합니다

| 구간 | 기준 | 확인 간격 (주기 20초 기준) |
|---|---|---|
| 임박 | 상영 2시간 이내 | 20초 |
| 오늘/내일 | 24시간 이내 | 40초 |
| 3일내 | 72시간 이내 | 100초 |
| 여유 | 그 이후 | 240초 |

최근 취소가 있었던 회차는 ×0.4(더 자주), 거의 매진이면 ×0.7, 자리가 절반 이상 남았으면 ×2.
잔여석 수가 그대로면 좌석 구성도 그대로일 가능성이 높아 건너뛰되, 임박 회차는 2번·먼 회차는
6번마다 강제로 실제 조회합니다.

실측(월드타워·오디세이·3일치 109회차): **첫 주기 113회 → 이후 주기 2~3회 호출**.

변동은 `history.jsonl` 에 한 줄씩 쌓이고 화면에도 표시됩니다. 알림에는 맥락이 함께 갑니다 —
`최근 1시간 취소 3회(+4석) · 판매 12석 · 잔여 2/295`.

## 명당 자동 추천 (롯데시네마 · 메가박스)

좌석 번호를 직접 고르지 않아도 됩니다. API의 `SweetSpotYN` 필드는 전 좌석이 `N`이라 쓸 수 없어,
**좌석 좌표로 직접 계산**합니다 — `X`는 좌우, `Y`는 스크린에서 멀어지는 방향(A열이 최소값)이라는
걸 실측으로 확인하고, `좌우 정중앙 · 앞에서 62% 뒤`를 기준점으로 거리 점수를 매깁니다.

검증: 월드타워 21관에서 최상위로 뽑힌 좌석이 `G22, G23, G21, G24 …` 였습니다.

```

K    ■■■■■■■■◆◆◆◆◆·◆◆◆◆■■■■■■■■

   ◆ 명당 49석 가능   ■ 그 외 가능   · 불가
```

## 예매 오픈 패턴 (언제 열리는지)

영화관들은 오픈 일정을 공지하지 않습니다. 대신 관측 가능한 사실이 하나 있습니다 —
**지금 예매가 열려 있는 마지막 날짜(horizon)**. 이 값이 늘어난 순간이 곧 오픈 순간입니다.

이진탐색으로 현재 범위를 재고(45일 범위에 6~7회 호출), 날짜별 회차 수를 그려줍니다.
예매는 층이 나뉘어 열립니다:

```
│ D+0  08-28(금)  ████████████░░░░░░░░░░  25회차     ┐
│ D+4  09-01(화)  ██████████████████░░░░  38회차     ┘ 정규 편성
│ D+5  09-02(수)  ████████░░░░░░░░░░░░░░  17회차     ┐ 주요작
│ D+9  09-06(일)  ████████░░░░░░░░░░░░░░  18회차     ┘ 선행 오픈
│ D+10 09-07(월)  ░░░░░░░░░░░░░░░░░░░░░░  미오픈
```

**상주 관측**을 켜두면 주기적으로 범위를 재서 `openlog.jsonl`에 남기고, 범위가 늘어나는
순간을 포착해 알립니다. 기록이 쌓이면 요일·시각·주기·폭을 학습해 예측합니다:

| 패턴 | 판별 | 예측 방법 |
|---|---|---|
| batch (주 단위로 왕창) | 이벤트 간격 > 2일 | 학습한 요일·시각으로 앞으로 굴려 목표일이 범위에 드는 시점 |
| rolling (매일 조금씩) | 이벤트 간격 ≤ 2일 | 현재 범위와의 차이만큼 뒤 |

```
│ 2026-09-08(화)  [예상] 2026-09-03(목) 10시 무렵
│               7일마다 7일치씩 여는 패턴 · 관측 3회 · 신뢰도 보통
```

관측 이력이 없으면 현재 범위만으로 역산하고 `신뢰도 낮음`으로 표시합니다.

## 좌석 지정 방법 (롯데시네마 · 메가박스)

| 방식 | 입력 예 | 판정 |
|---|---|---|
| 좌석 직접 지정 | `G22,G23 \| F22,F23` | 콤마로 묶인 한 그룹이 **전부** 비면 알림 (`\|` 는 대안) |
| 명당 자동 추천 | 인원 2, 상위 20% | 명당 영역 안에서 붙어있는 2석이 나면 알림 |
| 연속 N석 | 인원 2, 선호 열 `F,G,H` | 같은 열에서 **붙어있는** 2석 (통로로 끊기면 별개) |
| 아무 자리나 | 인원 2 | 잔여석이 2석 이상이면 알림 |

좌석을 입력하면 **해당 상영관에 그 번호가 실제로 있는지 대조**합니다.
21관 같은 리클라이너관은 통로 때문에 번호가 띄엄띄엄해서(A열이 5,6,7,8,12,13…),
없는 번호를 넣으면 영원히 알림이 오지 않기 때문입니다.

## 알림

- 소리 · Discord/Slack 웹훅 · 텔레그램 봇 · 예매 페이지 자동 열기
- 기본은 **상태가 바뀔 때만** 알립니다. 팔렸다가 다시 비면 다시 알립니다.

  `winsound.Beep` 은 메인보드 비프 스피커로 나가는데 요즘 PC엔 그 스피커가 없어
  아무 소리도 안 나는 경우가 많아 쓰지 않습니다.
- 저장 파일: 설정 `profiles.json`, 즐겨찾기 `favorites.json`,
  좌석 변동 `history.jsonl`, 오픈 관측 `openlog.jsonl`, 환경설정 `settings.json`

## 설정

메뉴의 **설정**에서 전역 환경설정을 바꿉니다. 값은 `settings.json`에 저장됩니다.

| 항목 | 설명 | 기본값 |
|---|---|---|
| 시작 배너 로고 | 배너 ASCII 로고 표시 여부 (끄면 로고 생략 + 대기 없이 진행) | 켜짐 |
| 배너 유지 시간 | 정보성 배너를 몇 초 보여줄지 (0~10초) | 3초 |
| 알림 소리 | 알림음 전역 스위치. 회차별 설정과 **둘 다 켜야** 소리가 남 | 켜짐 |
| 알림음 종류 | 알람 · 벨소리 · 알림음 · 차임 중 선택 (`p` 로 미리듣기, 다른 키로 정지) | 알람 |
| 알림 소리 테스트 | 지금 한 번 울려서 소리가 나는지 확인 | — |
| 인증 등록 | 로그인 연동 (다음 버전 예정) | 준비 중 |

## 사용하는 API

모두 로그인 없이 응답하는 공개 조회 엔드포인트입니다 (2026-08-28 확인).

**롯데시네마** — `multipart/form-data` 의 `paramList` 에 JSON 한 덩어리

| 용도 | 엔드포인트 / MethodName |
|---|---|
| 극장 목록 | `Cinema/CinemaData.aspx` / `GetCinemaItems` |
| 상영시간표 | `Ticketing/TicketingData.aspx` / `GetPlaySequence` |
| 좌석표 | `Ticketing/TicketingData.aspx` / `GetSeats` |

**메가박스** — JSON POST

| 용도 | 엔드포인트 |
|---|---|
| 지역·지점 목록 | `/on/oh/ohb/PlayTime/selectPlayTimeMasterList.do` |
| 상영시간표 + 잔여석 | `/on/oh/ohc/Brch/schedulePage.do` (`brchNo1` 로 지점 지정) |
| 좌석표 | `/on/oh/ohz/PcntSeatChoi/selectSeatList.do` (`playSchdlNo` + `brchNo`) |

**CGV** — JSON GET. 실제 호스트는 `api.cgv.co.kr` 이지만 직접 부르면 401 이고,
`cgv.co.kr/api/v1/booking/` 프록시로는 열립니다.

| 용도 | 엔드포인트 |
|---|---|
| 지역·극장 목록 | `/api/v1/booking/searchRegnList?coCd=A420` |
| 상영시간표 + 잔여석 | `/api/v1/booking/searchMovScnInfo` (`coCd`+`siteNo`+`scnYmd`+`rtctlScopCd=1`) |
| 예매 가능 날짜 | `/api/v1/booking/searchSiteScnscYmdListBySite` |

### 데이터 해석에서 주의한 점

- 롯데 `GetPlaySequence` 의 `BookingSeatCount` 는 예매된 수가 아니라 **잔여** 좌석 수입니다
  (좌석표와 대조 확인).
- 좌석 상태는 `SeatStatusCode`(0=가능, 50=예매완료)와 `BookingSeats` 를 교차 검증합니다.
- 같은 회차가 좌석 구역별로 두 줄(예: `씨네패밀리` 18석 + `일반` 342석)로 내려오는 경우가
  있어 하나로 합칩니다. 합치면 상영표의 잔여석이 좌석표(360석)와 정확히 일치합니다.
- 이미 시작한 회차는 건너뛰고, 매진 회차는 좌석표를 받지 않아 호출을 아낍니다.

## 참고

- **조회 전용입니다. 예매·결제·로그인은 하지 않습니다.**
- API 호출 간격은 0.6초로 제한돼 있습니다. 한 바퀴가 확인 주기보다 오래 걸리면
  화면에 알려주니 상영관·요일·시간대를 좁히세요.
- 색상·박스가 깨지는 터미널에서는 자동으로 단순 출력으로 전환됩니다.
  (Windows Terminal / PowerShell 7 권장)
- 내부 API는 예고 없이 바뀔 수 있습니다.
- 각 영화관 이용약관은 자동화 도구 사용을 제한할 수 있습니다. 본인 표를 구하는 용도로만 쓰세요.
